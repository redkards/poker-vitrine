2. Mise en ligne de la v0.7.0 sur la bêta — à faire par le propriétaire

Dans le Terminal cPanel d'o2switch, lancer dans l'ordre :

bash ~/poker-winners/deploy/update.sh
cd ~/poker-winners/backPoker
php bin/console app:content:seed --shop-demo --env=prod
php bin/console app:user:premium redkardss@gmail.com --months=1 --env=prod
  1. Met à jour l'API (avec les migrations de base) et le site bêta.
  2. Ajoute les produits fictifs de la boutique et passe en Premium les vidéos avancées déjà en base (peut être relancée sans risque).
  3. Rend le compte administrateur Premium pendant 1 mois pour tester (--revoke pour le retirer).

3. Points de vigilance

Paiement : aucun paiement réel n'est possible (Premium et boutique). Ne pas ouvrir le paiement avant les CGV, le médiateur de la consommation et la configuration Stripe.
Boutique : visible uniquement sur la bêta ; elle est désactivée dans la version publique.
Dossier pdfPoker/ : documents personnels, volontairement exclus de Git.
Mots de passe : ne jamais les coller dans le chat.
