1. Où en est le projet

Les fondations, l'authentification complète (backend + frontend) et le backend du contenu public (articles, vidéos, back-office) sont terminés et testés. Le site tourne en local avec un design validé. Il reste à brancher les pages Angular Actualités et Vidéos sur l'API (fin du Sprint 2), puis le forum, le profil RGPD, les finitions et le déploiement sur o2switch.

Point d'attention principal : Docker n'est pas encore installé. La base PostgreSQL, Mailhog (emails de test) et les migrations n'ont donc jamais été exécutés « pour de vrai ». Les tests et l'aperçu tournent sur SQLite. Les 3 migrations ont été écrites à la main et doivent être vérifiées avec doctrine:migrations:diff une fois Docker en place.

4. Déploiement prévu sur o2switch

  • Hébergement mutualisé : pas de Docker sur le serveur.
  • API Symfony sur un sous-domaine (ex. api.pokervitrine.fr) pointant vers backPoker/public.
  • Front Angular compilé (ng build) et servi par Apache, avec une règle .htaccess pour les routes.
  • Base : PostgreSQL si l'offre le permet (à vérifier dans le cPanel), sinon passage à MySQL.
  • Emails via le SMTP o2switch ; tâches RGPD via les crons du cPanel.
  • Mercure (temps réel) non utilisable sur un mutualisé : pas de temps réel en production.

6. Lancer le projet en local

API (port 8000)

cd backPoker
php -S localhost:8000 -t public public/index.php

Back-office : http://localhost:8000/admin

Site (port 4300)

cd frontPoker
npx ng serve --port 4300

Le port 4200 est occupé par le projet ESCT Boxe.

Comptes de démonstration (base locale uniquement) : demo@pokervitrine.local (membre) et admin@pokervitrine.local (administrateur), mot de passe Demo-Poker-2026!. Tests backend : php bin/phpunit dans backPoker.
