1. Où en est le projet

Le MVP est fonctionnellement complet en local : authentification, actualités, forum modéré, vidéos, parcours d'apprentissage, calendrier des tournois, profil et RGPD, pages légales. La base MariaDB 10.6 tourne sous Docker, identique à celle d'o2switch. Le projet est désormais totalement séparé d'ESCT Boxe (CLAUDE.md propre, ports distincts). Restent la mise en ligne de la bêta, la migration vers Angular 22 et le remplissage des mentions légales.

Point bloquant : le déploiement de la bêta sur o2switch attend l'autorisation SSH de l'adresse IP dans le cPanel (menu « Autorisation SSH »). Dès qu'elle est accordée : deploy/server-setup.sh puis deploy/publish-front.sh. Aucune mise en ligne publique sans confirmation du propriétaire.

7. Lancer le projet en local

API (port 8000)

docker compose up -d (MariaDB 3307, Mailhog 8025)
cd backPoker
php -S localhost:8000 -t public public/index.php

Back-office : http://localhost:8000/admin

Site (port 4300)

cd frontPoker
npx ng serve --port 4300

Ports distincts d'ESCT Boxe : les deux projets sont séparés.

Comptes de démonstration (base locale uniquement) : demo@pokervitrine.local (membre) et admin@pokervitrine.local (administrateur), mot de passe Demo-Poker-2026!. Tests backend : php bin/phpunit dans backPoker. Emails de test : http://localhost:8025.
